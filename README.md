# 🏏 IPL Crunch Analysis 2020–2024

## Overview
Ball-by-ball analysis of 333 IPL matches across 
5 seasons to answer 3 data-backed questions.

## Questions Answered
1. Do toss winners win more? → No (48% win rate)
2. Which phase matters most? → Powerplay
3. Top 5 batters & bowlers across 5 seasons

## Surprising Finding
Losing teams outscore winning teams in death overs — 
powerplay dominance is the real match differentiator.

## Tools Used
- Python (pandas, numpy, matplotlib, seaborn)
- Google Colab
- Power BI Desktop
